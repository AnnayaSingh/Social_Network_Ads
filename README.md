<h1 align="center">🌳 Decision Tree Classification Project</h1>

<p align="center">
A Machine Learning project demonstrating how to build and visualize a <b>Decision Tree Classifier</b> using Python and Scikit-learn.
</p>

<hr>

<h2>📌 Overview</h2>

<p>
This project implements a <b>Decision Tree Classification model</b> to predict whether a user will purchase a product based on features such as <b>Age</b> and <b>Estimated Salary</b>.
</p>

<p>The workflow includes:</p>

<ul>
<li>Data preprocessing</li>
<li>Feature scaling</li>
<li>Train-test split</li>
<li>Model training using Decision Tree</li>
<li>Model evaluation using confusion matrix</li>
<li>Decision tree visualization</li>
</ul>

<h2>▶️ How to Run the Project</h2>

<p><b>1. Clone the repository</b></p>
